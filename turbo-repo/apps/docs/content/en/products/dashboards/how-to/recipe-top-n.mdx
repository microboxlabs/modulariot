# Recipe: top N as a horizontal bar

**For:** implementers. **Setup:** ModularIoT.

**Result:** a ranking of the 5 owners with the most requests, from highest to lowest, with the value at the end of each bar.

![Top 5 owners as horizontal bars with labels](/dashboards/chart_v2/bar-horizontal.png)

## Before you start

| Step | Where |
| --- | --- |
| Save each SQL query with a name | **Settings › Connections › BigQuery** › **+ New** › **Save** |
| Add a saved query to the dashboard | With **Edit Mode** on: settings menu (gear) › **Saved queries** › **Add query**. **Connection**: your BigQuery connection. **Operation**: the SQL query's name |
| Add a widget | With **Edit Mode** on: **Add Widget** |

The full walkthrough is in [Build your first dashboard](/en/products/dashboards/tutorials/first-dashboard).

## Query

```sql
SELECT responsable, COUNT(*) AS cantidad
FROM `my-project.operations.solicitudes`
GROUP BY responsable
ORDER BY cantidad DESC
LIMIT 5
```

Save it as `top_responsables`. The chart does not sort: the order comes from `ORDER BY`. The first row is at the top.

## Steps

1. Turn on **Edit Mode**. Add the saved query **Result name** `top`, **Operation** `top_responsables`, **Parameters (JSON)** `{}`.
2. **Add Widget** › search `Chart` › **Chart v2**. **Data Provider**: **Planner**, **Variable** `top`.
3. **Visualization**:

   | Setting | Value |
   | --- | --- |
   | **Title** | `Top 5 owners` |
   | **Chart Family** | Cartesian |
   | **X-Axis Column** | `responsable` |
   | **Representations** | The widget comes with two (bar and line). Delete the line. On the bar: column `cantidad`, label `Requests`, **Labels** on |
   | **Horizontal Bars** | On |
   | **Show Legend** | Off |

4. **Save**.

## Variants

| You want | Change |
| --- | --- |
| The top 10 | `LIMIT 10` and a taller widget |
| The bottom (fewest requests) | `ORDER BY cantidad ASC` |
| Color by value | **Colors & Rules**: for example `>` `10` red. See [Chart v2](/en/products/dashboards/reference/widgets/chart-v2#color-rules) |
| Long names | They are cut at 120 pixels. Shorten them in the query |

The label of the longest bar can be cut at the right edge, as in the screenshot ([#2246](https://github.com/microboxlabs/modulariot/issues/2246)).
