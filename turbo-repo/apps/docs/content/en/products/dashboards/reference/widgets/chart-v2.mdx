# Chart v2

**For:** implementers. **`componentId`:** `chart_v2`. **Setup:** setting labels are the ModularIoT ones.

Bar, line, scatter, pie and gauge charts. One chart can mix bars and lines, stack series and use two Y axes.

## Data it reads

| Family | Reads | Query shape |
| --- | --- | --- |
| Cartesian (bars, lines, scatter) | All rows, in their order | One row per X-axis category. One column per series |
| Pie | All rows, in their order | One row per slice: name column + value column |
| Gauge | The first row | One row with a numeric column |

The chart does not sort or group rows: use `ORDER BY` and `GROUP BY` in the query. An empty or non-numeric value leaves a gap.

![Bars with the warm palette](/dashboards/chart_v2/palette-warm.png)

The UI has no palette selector and always saves `colorPalette: "custom"`. A named palette (`default`, `cool`, `warm`, `monochrome`, `pastel`, `vivid`) is used only if you write it in the document ([Import and export](/en/products/dashboards/how-to/import-export)). The palette is lost when you save the widget settings in the UI.

## Settings

| Section | Setting | Document key | Effect |
| --- | --- | --- | --- |
| General | **Title** | `title` | Accepts templates |
| General | **Chart Family** | `chartFamily` (`cartesian`, `pie`, `gauge`) | Switching to Pie or Gauge keeps only the first representation |
| Data Mapping | **X-Axis Column** (Pie: **Category Column**) | `xAxisColumn` | Category column. Not in Gauge |
| Data Mapping | **Representations** › type | `representations[].type` (`bar`, `line`, `scatter`) | Cartesian only |
| Data Mapping | **Representations** › column and label | `columnKey`, `label` | The label is the legend name. Accepts templates |
| Data Mapping | **Representations** › color | `customColors[i]` | Color of series `i` |
| Data Mapping | **Smooth** (line) | `smooth` | Smooth curve |
| Data Mapping | **Stacked** (line or bar) | `stacked` | Every series with Stacked shares one stack |
| Data Mapping | **Labels** (bar) | `showLabels` | Value on each bar |
| Data Mapping | **L** / **R** (with dual axis) | `yAxisIndex` (0, 1) | Axis of the series |
| Appearance | **X-Axis Label**, **Y-Axis Label** | `xAxisLabel`, `yAxisLabel` | Axis names |
| Appearance | **Right Y-Axis Label** | `yAxisLabelRight` | Dual axis only. Does not accept templates |
| Appearance | **Show Legend** | `showLegend` | Legend at the bottom |
| Appearance | **Horizontal Bars** | `horizontal` | Only when every representation is a bar |
| Appearance | **Dual Y-Axis** | `dualYAxis` | Second axis on the right |
| Appearance | **X-Axis is a Date** | `xAxisDateFormat` (`month`) | Shows the range buttons |
| Colors & Rules | **Value Color Rules** | `valueColorRules.rules[]` | Color of a point by its value |
| Tooltip | Template | `tooltipTemplate` | Text on hover. Uses `{{row.column}}` |
| Data Provider | **Data Source**: Planner or Static | `dataMode`, `plannerVariableName`, `rows` | In static mode, rows go in `rows` |

## Colors

| What | Color |
| --- | --- |
| A series (bars or lines) | `customColors[i]`. If missing, the chart's color list at that position |
| A pie slice | The chart's color list, in row order |
| A point that matches a rule | The rule's color |

<Callout type="warning">
**Pitfall:** in a pie, if you pick a color for its only representation, **every slice** takes that color. Do not pick a color in a pie. For a fixed color per state, use [One color per state](#one-color-per-state) or a Stacked Stat.
</Callout>

Once a representation has a color, the chart's color list becomes `customColors`. Give every representation a color; otherwise the ones without a color repeat others' colors.

### Color rules

| Field | Values |
| --- | --- |
| Operator | `=`, `!=`, `contains`, `!contains`, `>`, `<`, `>=`, `<=` |
| Value | Number or text |
| Color | Hex |

Rules compare **each point's numeric value**, not the category name or another column. `>` and `>=` rules are checked from highest to lowest value, then `<` and `<=` from lowest to highest. The first match wins. On a line, the rule colors the point, not the stroke.

### Tooltip

With the field empty, the tooltip shows every series at the category. With a template, it shows the text of the row under the cursor:

```text
{{row.responsable}}: {{row.atrasadas}} late
```

The template has no access to the series name or to filters.

## Full example

```json
{
  "componentId": "chart_v2",
  "config": {
    "title": "Solicitudes por mes y estado",
    "chartFamily": "cartesian",
    "xAxisColumn": "mes",
    "representations": [
      { "columnKey": "pendiente", "label": "Pendiente", "type": "bar", "stacked": true },
      { "columnKey": "en_curso", "label": "En curso", "type": "bar", "stacked": true },
      { "columnKey": "cerrada", "label": "Cerrada", "type": "bar", "stacked": true }
    ],
    "colorPalette": "custom",
    "customColors": ["#eab308", "#3b82f6", "#22c55e"],
    "showLegend": true,
    "horizontal": false,
    "xAxisLabel": "",
    "yAxisLabel": "",
    "dataMode": "planner",
    "plannerVariableName": "por_mes"
  }
}
```

Always include `customColors`, even as `[]`: without that key, the widget fails.

## Limits

| Limit | Alternative |
| --- | --- |
| Clicking a bar or slice does not filter other widgets | Use a dashboard select filter |
| No color per category in the pie | [One color per state](#one-color-per-state) or Stacked Stat |
| The gauge goes from 0 to 100 | Send a percentage |
| The date axis does not sort or fill days without data | Sort and fill the days in the query |
| A date without time (`2026-01-01`) shows one day earlier in Chile | Send the date with a time: `2026-01-01T12:00:00` |
| The palette and the initial range (`defaultDateRange`) are lost when you save the settings in the UI | Import them again in the document |
| The value label of the longest bar can be cut off at the edge | None for now |
