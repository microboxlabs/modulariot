# Brand assets

The only supported ModularIoT platform logo is **"Lynx"** — the Golden Owl
drawn with phi-based geometry and its signature re-pinned tufts closing an
exact 2√5 square. Ink `#13273D` / amber `#E08A28` on light surfaces
(`#E8EFF7` / `#F5AE55` on dark), adaptive via `prefers-color-scheme`.

Canonical sources are generated by `apps/web/scripts/generate-logo.mjs`:
`apps/web/public/{logo,logo-dark,headlogo,headlogo-dark}.svg`,
`apps/web/app/icon.svg`, plus the inline React components
(`LynxMark`, `LynxWordmark`, `LynxLockup`) in `packages/ui/src/brand/`.
The same assets ship under `apps/web-admin/public/`.

## What used to be here

The legacy illustrated owl from the design-system export previously lived
here (`logo-modulariot{,-mark}.svg`) and under
`apps/web-admin/public/{logo,headlogo,headlogo-dark}.svg`. It was removed in
[#1114](https://github.com/microboxlabs/modulariot/issues/1114) and replaced
with "Lynx" — the only supported platform logo.

## Tenant-vs-platform reminder

These are **platform** assets — every tenant implementation gets its own logo
slotted in via the same dimensions and clear-space rules. Tenant logos are NOT
shipped on this marketing site; they live under `assets/tenants/<tenant>/` in
the design system and are loaded only inside the secured app surfaces a given
tenant runs.
