# Contrato de Dashboards

El paquete independiente de frameworks `@microboxlabs/miot-dashboard-contract` define el documento persistido, los roles, JSON Schema y la especificación OpenAPI.

- Tipos y validación compartidos entre servidor, interfaz y un backoffice independiente.
- Definiciones de consultas basadas en conexiones, con valores fijos o filtros identificados por nombre.
- Compatibilidad con los dashboards de versión 2. La ejecución y autorización corresponden al servidor y a los adaptadores del host.
