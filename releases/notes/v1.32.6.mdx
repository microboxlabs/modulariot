# 🔔 Release Notes v1.32.6 — ModularIoT

### Fecha: 10/11/2026

**Objetivo**: Coordinar el alcance del milestone privado Release 1.32.6 con las integraciones OSS del milestone MIOT-0.6.6. Esta versión alinea las versiones de los componentes incluidos en el plan de release.

## 🔧 Integraciones

- **🔌 Integración del milestone OSS MIOT-0.6.6**
  - **Alcance**: Se incorpora al alcance coordinado de esta release junto con el milestone privado.

## 📊 Beneficios

- Versiones de los componentes coordinadas bajo el stack 0.6.6.
- App, Docs y Web cuentan con nuevas etiquetas de release.
- Modulith cuenta con una nueva etiqueta de release.
- El plan distingue los componentes actualizados de los que mantienen su versión.
- El alcance OSS queda identificado por el milestone MIOT-0.6.6.
- Los digests exactos de las imágenes desplegadas se pueden consultar en el diálogo de información de build de la aplicación y en el asset `stack-manifest.json` de la release.

## 🧾 Versiones del stack

- Stack: `miot-stack@v0.6.6`
- App: `app@v0.6.6` (actualizada)
- Docs: `docs@v0.6.6` (actualizada)
- Web: `web@v0.6.6` (actualizada)
- Modulith: `modulith@v0.5.45` (actualizada)
- Harness: `harness@v0.1.15` (sin cambios)

## 📌 Conclusión

La release v1.32.6 coordina el milestone privado con las integraciones OSS de MIOT-0.6.6 y registra las versiones previstas de cada componente.

El plan facilita identificar qué componentes tienen una nueva versión y dónde consultar los digests exactos de las imágenes desplegadas.
