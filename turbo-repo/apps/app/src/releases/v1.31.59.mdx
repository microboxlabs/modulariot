# 🔔 Release Notes v1.31.59 — ModularIoT

### Fecha: 10/10/2026

**Objetivo**: Esta versión vuelve a mostrar en la línea de tiempo de síntomas el comentario que registra el operador al gestionar una llamada.

## 🐛 Correcciones

- **🐛 Comentario de las llamadas en la línea de tiempo** *(Integración OSS — MIOT-0.5.60)*
  - **Impacto**: Al abrir un "Tratamiento" de tipo llamada al conductor, la tarjeta aparecía vacía: no se veían el mensaje comunicado ni el comentario del operador.
  - **Solución**: Cada tratamiento de llamada muestra el mensaje comunicado y, debajo, la respuesta o comentario registrado por el operador.
