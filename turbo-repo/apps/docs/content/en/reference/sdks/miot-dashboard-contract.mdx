# Dashboard Contract

The framework-independent `@microboxlabs/miot-dashboard-contract` package defines the persisted dashboard document, role vocabulary, JSON Schema and OpenAPI specification.

- Shared types and validation for server, browser UI and an independent backoffice.
- Additive connection-backed query definitions with fixed values or named filter bindings.
- Existing version-2 dashboards remain compatible. Query execution and authorization belong to the server and host adapters.
