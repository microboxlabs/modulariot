# Chart v2

**Para:** implementadores. **`componentId`:** `chart_v2`. **Configuración:** las etiquetas de los ajustes son las de ModularIoT.

Gráficos de barras, líneas, dispersión, torta e indicador. En un mismo gráfico puede mezclar barras y líneas, apilar series y usar dos ejes Y.

## Datos que lee

| Familia | Lee | Forma de la consulta |
| --- | --- | --- |
| Cartesiano (barras, líneas, dispersión) | Todas las filas, en su orden | Una fila por categoría del eje X. Una columna por serie |
| Torta | Todas las filas, en su orden | Una fila por porción: columna de nombre + columna de valor |
| Indicador | La primera fila | Una fila con una columna numérica |

El gráfico no ordena ni agrupa filas: use `ORDER BY` y `GROUP BY` en la consulta. Un valor vacío o que no es número queda como hueco.

## Variantes

| Variante | Ajustes | Forma de la consulta | Captura |
| --- | --- | --- | --- |

| Barras apiladas | Una representación por estado, todas con **Apilado** | `mes, pendiente, en_curso, cerrada` | [Barras apiladas](#barras-apiladas) |

### Un color por estado

![Barras amarilla, azul y verde, una por estado, con su valor encima](/dashboards/chart_v2/colors-per-state.png)

```sql
SELECT
  estado,
  IF(estado = 'pendiente', COUNT(*), NULL) AS pendiente,
  IF(estado = 'en_curso',  COUNT(*), NULL) AS en_curso,
  IF(estado = 'cerrada',   COUNT(*), NULL) AS cerrada
FROM `mi-proyecto.operaciones.solicitudes`
GROUP BY estado
```

Con **Apilado**, cada barra queda centrada en su categoría.

### Paleta

![Barras con la paleta warm](/dashboards/chart_v2/palette-warm.png)

La interfaz no tiene selector de paleta y guarda siempre `colorPalette: "custom"`. Una paleta con nombre (`default`, `cool`, `warm`, `monochrome`, `pastel`, `vivid`) solo se usa si la escribe en el documento ([Importar y exportar](/es/products/dashboards/how-to/import-export)). La paleta se pierde al guardar los ajustes del widget en la interfaz.

## Ajustes

| Sección | Ajuste | Clave en el documento | Efecto |
| --- | --- | --- | --- |
| General | **Título** | `title` | Acepta plantillas |
| General | **Familia de gráfico** | `chartFamily` (`cartesian`, `pie`, `gauge`) | Al pasar a Torta o Indicador se conserva solo la primera representación |
| Mapeo de datos | **Columna Eje X** (en Torta: **Columna de Categoría**) | `xAxisColumn` | Columna de las categorías. No existe en Indicador |
| Mapeo de datos | **Representaciones** › tipo | `representations[].type` (`bar`, `line`, `scatter`) | Solo en Cartesiano |
| Mapeo de datos | **Representaciones** › columna y etiqueta | `columnKey`, `label` | La etiqueta es el nombre en la leyenda. Acepta plantillas |
| Mapeo de datos | **Representaciones** › color | `customColors[i]` | Color de la serie `i` |
| Mapeo de datos | **Suavizado** (línea) | `smooth` | Curva suave |
| Mapeo de datos | **Apilado** (línea o barra) | `stacked` | Todas las series con Apilado comparten una pila |
| Mapeo de datos | **Etiquetas** (barra) | `showLabels` | Valor sobre cada barra |
| Mapeo de datos | **L** / **R** (con doble eje) | `yAxisIndex` (0, 1) | Eje de la serie |
| Apariencia | **Etiqueta Eje X**, **Etiqueta Eje Y** | `xAxisLabel`, `yAxisLabel` | Nombre de los ejes |
| Apariencia | **Etiqueta eje Y derecho** | `yAxisLabelRight` | Solo con doble eje. No acepta plantillas |
| Apariencia | **Mostrar Leyenda** | `showLegend` | Leyenda abajo |
| Apariencia | **Barras Horizontales** | `horizontal` | Solo si todas las representaciones son barras |
| Apariencia | **Doble eje Y** | `dualYAxis` | Segundo eje a la derecha |
| Apariencia | **El Eje X es una Fecha** | `xAxisDateFormat` (`month`) | Muestra los botones de rango |
| Colores y reglas | **Reglas de Color por Valor** | `valueColorRules.rules[]` | Color de un punto según su valor |
| Tooltip | Plantilla | `tooltipTemplate` | Texto al pasar el cursor. Usa `{{row.columna}}` |
| Proveedor de Datos | **Fuente de Datos**: Planificador o Estático | `dataMode`, `plannerVariableName`, `rows` | En modo estático, las filas van en `rows` |

## Colores

| Qué | Color |
| --- | --- |
| Una serie (barras o líneas) | `customColors[i]`. Si falta, el color de la lista del gráfico en esa posición |
| Una porción de la torta | La lista del gráfico, en el orden de las filas |
| Un punto que cumple una regla | El color de la regla |

<Callout type="warning">
**Cuidado:** en una torta, si elige un color para su única representación, **todas las porciones** toman ese color. No elija color en una torta. Para un color fijo por estado, use [Un color por estado](#un-color-por-estado) o un Stacked Stat.
</Callout>

Cuando una representación tiene color, la lista del gráfico pasa a ser `customColors`. Dé color a todas las representaciones; si no, las que no tienen color repiten los de otras.

### Reglas de color

| Campo | Valores |
| --- | --- |
| Operador | `=`, `!=`, `contains`, `!contains`, `>`, `<`, `>=`, `<=` |
| Valor | Número o texto |
| Color | Hexadecimal |

Las reglas comparan **el valor numérico de cada punto**, no el nombre de la categoría ni otra columna. Las reglas `>` y `>=` se evalúan de mayor a menor valor, luego `<` y `<=` de menor a mayor. Gana la primera que se cumple. En una línea, la regla colorea el punto, no el trazo.

### Tooltip

Con el campo vacío, el tooltip muestra todas las series de la categoría. Con una plantilla, muestra el texto de la fila bajo el cursor:

```text
{{row.responsable}}: {{row.atrasadas}} atrasadas
```

La plantilla no tiene acceso al nombre de la serie ni a los filtros.

## Ejemplo completo

```json
{
  "componentId": "chart_v2",
  "config": {
    "title": "Solicitudes por mes y estado",
    "chartFamily": "cartesian",
    "xAxisColumn": "mes",
    "representations": [
      { "columnKey": "pendiente", "label": "Pendiente", "type": "bar", "stacked": true },
      { "columnKey": "en_curso", "label": "En curso", "type": "bar", "stacked": true },
      { "columnKey": "cerrada", "label": "Cerrada", "type": "bar", "stacked": true }
    ],
    "colorPalette": "custom",
    "customColors": ["#eab308", "#3b82f6", "#22c55e"],
    "showLegend": true,
    "horizontal": false,
    "xAxisLabel": "",
    "yAxisLabel": "",
    "dataMode": "planner",
    "plannerVariableName": "por_mes"
  }
}
```

Incluya siempre `customColors`, aunque sea `[]`: sin esa clave, el widget falla.

## Límites

| Límite | Alternativa |
| --- | --- |
| Hacer clic en una barra o porción no filtra otros widgets | Use un filtro de selección del dashboard |
| No hay color por categoría en la torta | [Un color por estado](#un-color-por-estado) o Stacked Stat |
| El indicador va de 0 a 100 | Envíe un porcentaje |
| El eje de fecha no ordena ni rellena días sin datos | Ordene y complete los días en la consulta |
| Una fecha sin hora (`2026-01-01`) se muestra un día antes en Chile | Envíe la fecha con hora: `2026-01-01T12:00:00` |
| La paleta y el rango inicial (`defaultDateRange`) se pierden al guardar los ajustes en la interfaz | Vuelva a importarlos en el documento |
| La etiqueta de valor de la barra más larga puede quedar cortada en el borde | Ninguna por ahora |
