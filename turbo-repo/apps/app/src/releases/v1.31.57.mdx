# 🔔 Release Notes v1.31.57 — ModularIoT

### Fecha: 10/10/2026

**Objetivo**: Coordinar la actualización de la plataforma a la versión de stack 0.5.58 y dejar claros los componentes incluidos en el plan de release.

## 📊 Beneficios

- Facilita identificar las versiones de los componentes previstas para esta release.
- Hace visible qué componentes tienen cambios en el plan y cuáles conservan su versión.
- Ayuda a mantener alineadas las referencias de versión del stack, la aplicación, la documentación y la web.
- Permite consultar los digests exactos de las imágenes en la información de compilación de la aplicación y en el artefacto de release `stack-manifest.json`.

## 🧾 Versiones del stack

- Stack: `miot-stack@v0.5.58`
- App: `app@v0.5.58` — con cambios.
- Docs: `docs@v0.5.58` — con cambios.
- Web: `web@v0.5.58` — con cambios.
- Modulith: `modulith@v0.5.35` — sin cambios.
- Harness: `harness@v0.1.12` — sin cambios.

Los digests exactos de las imágenes desplegadas están disponibles en el diálogo de información de compilación de la aplicación y en el artefacto de release `stack-manifest.json`.

## 📌 Conclusión

La release 1.31.57 establece el plan de versiones para el stack 0.5.58, con cambios previstos en App, Docs y Web, mientras Modulith y Harness mantienen sus versiones.

No se proporcionaron incidencias para esta release, por lo que estas notas se limitan a resumir el plan de componentes y la información disponible para verificar las imágenes.
