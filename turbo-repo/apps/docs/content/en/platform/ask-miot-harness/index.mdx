# ASK MIOT Harness

The ASK MIOT Harness is the backend behind ASK MIOT. One language model, which the user chooses, answers questions about ModularIoT operational data by calling tools. The harness keeps control of those tools, the tenant context, permission checks, approvals and the record of every run.

## Purpose

ModularIoT collects large volumes of telemetry, symptoms and shipping data. The harness turns natural-language questions about that data into answers backed by evidence, without giving the model direct access to the database or to operations that change data.

## What the Harness Owns

- **Typed tools** — read and write operations the model may call, instead of raw SQL or API access.
- **Tenant and user context** — taken from authenticated server context, never from model-provided text.
- **Permission checks** — read-only tools run freely; tools that change data ask the user first.
- **Conversation memory** — each turn is kept with the tools it called, and long conversations are summarized.
- **Run records** — every run is recorded so it can be inspected and audited.

## Data Integration

The harness reads ModularIoT operational data through a standard Postgres connection string. Without a database it still answers, with no data tools.
