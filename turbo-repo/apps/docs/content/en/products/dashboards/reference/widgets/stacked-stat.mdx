# Stacked Stat

**For:** implementers. **`componentId`:** `stat_stacked`. **Setup:** setting labels are the ModularIoT ones.

Shows the parts of a total as a 100% bar or a donut, with a legend that gives each part's value. Use it for "a KPI per state + a 100% bar".

![Stacked Stat with the bar Pendiente 12, En curso 7, Cerrada 30](/dashboards/stat_stacked/templated.png)

## Data it reads

It reads **the first row** of its query. Each category reads one column of that row through a template:

```sql
SELECT
  COUNT(*) AS total,
  COUNTIF(estado = 'pendiente') AS pendiente,
  COUNTIF(estado = 'en_curso')  AS en_curso,
  COUNTIF(estado = 'cerrada')   AS cerrada
FROM `my-project.operations.solicitudes`
```

| Category | Value |
| --- | --- |
| Pending | `{{pendiente}}` |
| In progress | `{{en_curso}}` |
| Closed | `{{cerrada}}` |

If your query returns one row per state, turn it into columns: [Pivot](/en/products/dashboards/tutorials/queries-for-widgets#pivot-one-column-per-state).

## Settings

| Tab | Setting | Document key | Effect |
| --- | --- | --- | --- |
| Visualization | **Show Header** | `showHeader` | Shows or hides the title. On by default |
| Visualization | **Chart Type**: Bar / Donut | `chartType` (`bar`, `donut`) | Chart shape |
| Visualization | **Title** | `title` | Accepts templates |
| Visualization | **Unit** | `unit` | Text after each value, with no space. Default `%` |
| Visualization | **Categories** | `items[]`: `label`, `value`, `color` | One part per category. `color` in hex without `#` |
| Visualization | **Thresholds** | `thresholds` | Saved, but the widget does not use it |
| Data Provider | **Data Source**, **Variable** | `dataMode`, `plannerVariableName` | `planner` reads a saved query |
| Panel footer | **Auto-Refresh** | `refreshInterval` | Seconds between reloads. Empty: the dashboard setting |

## How the bar is computed

| Case | Result |
| --- | --- |
| Positive values | Each part is its value over the sum of the positive values |
| Value 0 or negative | No part is drawn. The legend shows the value |
| Value that is not a number | Treated as 0 |
| Every value 0 | The bar is grey |
| Color that is not a 6-digit hex | Grey (`9ca3af`) |

Hovering a part shows `Label: value (percentage)`.

## Full example

```json
{
  "componentId": "stat_stacked",
  "config": {
    "title": "Solicitudes por estado ({{total}})",
    "unit": "",
    "showHeader": true,
    "chartType": "bar",
    "dataMode": "planner",
    "plannerVariableName": "resumen",
    "items": [
      { "label": "Pendiente", "value": "{{pendiente}}", "color": "eab308" },
      { "label": "En curso", "value": "{{en_curso}}", "color": "3b82f6" },
      { "label": "Cerrada", "value": "{{cerrada}}", "color": "22c55e" }
    ]
  }
}
```

## Limits

<Callout type="warning">
**Pitfall:** in the ModularIoT setup, category templates resolve only with **Data Source: Planner**. With **Static (JSON)**, `{{pendiente}}` shows as 0. The title and unit resolve in both modes.
</Callout>

| Limit | Alternative |
| --- | --- |
| Reads only the first row | Pivot the query: one column per category |
| Categories are fixed; a new state does not appear on its own | Add the column and the category |
| The legend is a list; there are no cards per category | Add a Stat Card per state with the same query |
| Clicking a part does not filter other widgets | Use a dashboard select filter |
| The Data Provider tab has no static JSON editor | Use a saved query |
| Category templates do not read `{{filter.…}}` | Put the filter value in the title |
