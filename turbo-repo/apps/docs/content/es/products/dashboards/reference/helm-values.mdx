# Valores de Helm

Valores del chart `miot-dashboard-server`, versión 0.1.2. Cada valor que establece una variable de entorno la indica. Las opciones sin un valor propio van en `extraEnv` o `extraEnvFrom`.

## Carga de trabajo

| Valor | Valor por defecto | Significado |
| --- | --- | --- |
| `replicaCount` | `1` | Mantenga 1 con SQLite |
| `strategy.type` | `Recreate` | `Recreate` detiene primero el pod anterior, de modo que dos pods nunca comparten un archivo SQLite |
| `image.repository` | `ghcr.io/microboxlabs/miot-dashboard-server` | Imagen |
| `image.tag` | `latest` | Fije una etiqueta `sha-<commit>` |
| `image.pullPolicy` | `Always` | Use `IfNotPresent` con una etiqueta fija |
| `resources` | `{}` | Solicitudes y límites de CPU y memoria |
| `podSecurityContext` | `fsGroup: 1001` | |
| `securityContext` | UID 1001 sin privilegios de root, raíz de solo lectura, sin escalada de privilegios, todas las capacidades eliminadas | |
| `nodeSelector`, `tolerations`, `affinity` | vacío | Planificación de pods |
| `volumes`, `volumeMounts` | vacío | Montajes adicionales, como un módulo de consultas de solo lectura |
| `extraEnv`, `extraEnvFrom` | vacío | Cualquier otra variable de entorno o secreto |

## Secretos

Cada valor sensible acepta un literal, que el chart guarda en un Secret que administra, o `existingSecret` y `existingSecretKey`, que apuntan a un Secret que usted creó. Use `existingSecret` en producción, para que los secretos no queden en los archivos de valores.
