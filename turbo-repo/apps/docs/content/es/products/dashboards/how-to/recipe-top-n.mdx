# Receta: los N primeros en barra horizontal

**Para:** implementadores. **Configuración:** ModularIoT.

**Resultado:** un ranking de los 5 responsables con más solicitudes, de mayor a menor, con el valor al final de cada barra.

![Top 5 responsables en barras horizontales con etiquetas](/dashboards/chart_v2/bar-horizontal.png)

## Consulta

```sql
SELECT responsable, COUNT(*) AS cantidad
FROM `mi-proyecto.operaciones.solicitudes`
GROUP BY responsable
ORDER BY cantidad DESC
LIMIT 5
```

El gráfico no ordena: el orden sale del `ORDER BY`. La primera fila queda arriba.

## Pasos

1. Agregue la consulta guardada `top_responsables` con **Parámetros (JSON)** `{}`.
2. **Agregar Widget** › **Chart v2**. **Proveedor de Datos**: **Planificador**, **Variable** `top_responsables`.
3. **Visualización**:

   | Ajuste | Valor |
   | --- | --- |
   | **Familia de gráfico** | Cartesiano |
   | **Columna Eje X** | `responsable` |
   | **Representaciones** | Una, **Barras**, columna `cantidad`, etiqueta `Solicitudes`, **Etiquetas** encendido |
   | **Barras Horizontales** | Encendido |
   | **Mostrar Leyenda** | Apagado |

4. **Guardar**.

## Variantes

| Quiere | Cambie |
| --- | --- |
| Los 10 primeros | `LIMIT 10` y más alto el widget |
| Los últimos (menos solicitudes) | `ORDER BY cantidad ASC` |
| Color según el valor | **Colores y reglas**: por ejemplo `>` `10` rojo. Vea [Chart v2](/es/products/dashboards/reference/widgets/chart-v2#reglas-de-color) |
| Nombres largos | Se cortan a 120 píxeles. Acórtelos en la consulta |
