# Recipe: one color per state

**For:** implementers. **Setup:** ModularIoT.

**Result:** each state always shows in the same color, in the summary, in a bar chart and in the table.

| State | Color |
| --- | --- |
| Pending | `eab308` (yellow) |
| In progress | `3b82f6` (blue) |
| Closed | `22c55e` (green) |

| Widget | How the color is fixed |
| --- | --- |
| Stacked Stat | One color per category in the settings |
| Chart v2 bars | One series per state, each with its color |
| Data Table V2 | One color rule per state on the column |
| Chart v2 pie | Only by editing the document |

## Bars with one color per state

![Yellow, blue and green bars, one per state](/dashboards/chart_v2/colors-per-state.png)

A bar chart colors by series. The query returns one column per state, with a value only in its state's row. It assumes three states. Save it as `barras_por_estado`:

```sql
SELECT
  CASE estado WHEN 'pendiente' THEN 'Pending' WHEN 'en_curso' THEN 'In progress' ELSE 'Closed' END AS etiqueta,
  IF(estado = 'pendiente', COUNT(*), NULL) AS pendiente,
  IF(estado = 'en_curso',  COUNT(*), NULL) AS en_curso,
  IF(estado = 'cerrada',   COUNT(*), NULL) AS cerrada
FROM `my-project.operations.solicitudes`
GROUP BY estado
ORDER BY CASE estado WHEN 'pendiente' THEN 1 WHEN 'en_curso' THEN 2 ELSE 3 END
```

1. Add the saved query **Result name** `barras`, **Operation** `barras_por_estado`.
2. **Add Widget** › **Chart v2**. **Data Provider**: **Planner**, **Variable** `barras`.
3. **Visualization**:

   | Setting | Value |
   | --- | --- |
   | **X-Axis Column** | `etiqueta` |
   | **Representations** | The widget comes with a bar and a line. Change the line to **Bar** and add a third with **Add representation**. Columns `pendiente`, `en_curso`, `cerrada`, with the colors from the table above. All three with **Stacked** and **Labels** |
   | **Show Legend** | Off |

4. **Save**.

With **Stacked**, each bar is centered on its category. Give all three representations a color.

## Pie

<Callout type="warning">
In a pie, choosing a color for its representation paints **every** slice that color ([#2240](https://github.com/microboxlabs/modulariot/issues/2240)). If you already chose one, delete the representation and add it again.
</Callout>

To fix one color per state in the pie, edit the document ([Import and export](/en/products/dashboards/how-to/import-export)): `"colorPalette": "custom"`, `"customColors": ["#eab308", "#3b82f6", "#22c55e"]`, and sort the rows with the same `ORDER BY` as above. If a state has no rows, the colors shift.
